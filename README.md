1. Manejo de Datos (POO)
Creamos la clase Paciente con los datos que nos pidieron: CURP (que es el ID único), nombre, edad, teléfono y las alergias. También le agregamos un campo de "estatus" para saber si el paciente está Activo o Inactivo
2. validaciones
Le metimos candados sencillos para que no truene:
El nombre tiene que ser de más de 5 letras.
La edad no puede ser negativa ni mayor a 120.
El teléfono debe ser de 10 números.
No deja registrar dos veces la misma CURP.
